Talk privately. Leave nothing behind.

RelayChat is a Windows app for one-to-one conversations. No account, no phone number, no history. Messages are encrypted on your computer, and when one of you leaves, the conversation disappears for both.

Download for Windows See how it works

Free beta for Windows 10 and 11. It has not been independently audited yet, so please read the limits below before you rely on it.

C:\ghost>How it works

Four steps, all typed in the app. There is nothing to sign up for.

  1. 1

    Create a room

    Type /create and choose how long the chat may last. You get a one-time room code.

  2. 2

    Share the code

    Send it to the other person over a channel you trust. It works for 5 minutes, and only while you are waiting for them.

  3. 3

    They join

    They type /join and paste the code. Both screens show Secure channel established and a short fingerprint you can compare.

  4. 4

    Talk, then leave

    When either of you types /leave or closes the window, the chat ends and both screens are wiped. Nothing is kept.

C:\ghost>What you get

Each feature does one plain job.

No accounts
No phone number, email or username. Each session gets a random alias such as anon-31ac.
Nothing saved
Messages exist only in memory while the chat is open. The app keeps its working files in a temporary folder that is deleted when you close it.
Encrypted on your device
Only the two of you can read the messages. The server passes along scrambled data that it cannot open.
Exactly two people
A room holds two participants. If a third person tries to use the code, they are turned away.
A time limit you choose
When you create a room you set how long the chat may last, from 1 to 240 minutes. A warning appears 60 seconds before it closes and wipes everything.
Screen protection
The window is hidden from most screenshot and screen-recording tools on Windows. It cannot stop a camera pointed at your screen.
Locked copy and paste
The conversation cannot be selected or copied. Only the room code can be copied, and only a room code can be pasted, right after /join.
A typing indicator that shows nothing
The other person sees animated dots while you type, never what you type. Turn it off with /live off.
Optional Tor
With /tor the connection goes through the Tor proxy on your computer, so the server does not see your real IP address. Tor must already be running.

C:\ghost>Why you don't have to trust the server

The server never has the keys. It only passes scrambled data between two computers, and it forgets the room when the chat ends.

YouEncrypt the message on your computer.
Relay serverPasses data along. Cannot read it. Keeps nothing after the chat ends.
ThemDecrypt the message on their computer.

Everything that travels between the two computers is scrambled.

The details, for people who want them

Room code
A 12-character room name plus a secret of 128 bits. The secret never leaves your devices. The server only sees a hash of it.
Key exchange
A fresh X25519 key pair for every conversation, authenticated with the room secret so the server cannot swap keys.
Key derivation
HKDF with SHA-256 turns the shared result into the session key.
Messages
AES-256-GCM with a new random nonce for every message. Sequence numbers block replayed messages.
Padding
Messages are padded to 256-byte blocks, so their length gives little away.
Forward secrecy
Keys exist only for that conversation and are wiped when it ends, so an old recording cannot be opened later.

These are standard building blocks put together into a custom protocol. That protocol has not been reviewed by an independent security expert.

What the server can see

  • That a connection happened, and when.
  • Your IP address, unless you use Tor.
  • That a room has two participants.
  • The size of each message, in steps of 256 bytes.
  • When someone is typing (on or off, never the text).

What it cannot see

  • The text of your messages.
  • The room secret.
  • Who you are.
  • Any history. Rooms live in memory and are deleted when the chat ends.

The relay does not write per-connection logs. The counters it uses against abuse live in memory and disappear when you disconnect. The server's own system logs are kept in memory, not on disk, although technical error messages from its web layer can appear there briefly.

C:\ghost>What RelayChat does not protect

No chat app can do everything. These are the limits, stated plainly.

  • It is a beta, and it is not audited. It was built and tested by one person. If your safety depends on it, use an established app that has been reviewed by independent experts.
  • A camera beats any screen protection. Someone can photograph their screen, or simply retype what you wrote.
  • Malware on your computer defeats it. A keylogger or screen-capture tool running on your PC sees what you see.
  • Without Tor, the server sees your IP address. Encryption hides what you say, not the fact that you are talking. Use /tor if that matters.
  • Whoever has the room code can join first. Send it over a channel you trust. If your contact sees "room is full", assume the code leaked and start a new room. When it matters, compare the fingerprint by another route.
  • Windows may write memory to disk. Like any program, it can swap parts of memory to the page file. The app cannot prevent that.
  • Windows only, for now. There is no phone version yet.

C:\ghost>Questions

Short answers.

Do I have to install it?

No. RelayChat is one portable file. Double-click it to open it, and each time you open it you start fresh with /create or /join. To remove it, delete the file. It does not update itself: when a new version is out, download it and delete the old one.

Is RelayChat audited?

No. It is built from standard cryptographic parts and tested by its author, but no independent expert has reviewed it. Treat it as a beta.

Who runs the server?

The project runs one relay, and the app connects to it by default. Someone can run another and point the app to it with /relay.

Why only two people?

One-to-one keeps the design simple, and simple is easier to get right. Group chat needs a different protocol.

Can I use it on my phone?

Not yet. It is a Windows app today.

What if my internet connection drops?

The conversation ends for both of you. Create a new room to continue.

Can I hide my IP address from the server?

Yes, with Tor. Start Tor on your computer, then type /tor in the app. If you use Tor Browser, type /tor 9150.

Is it free?

Yes. Donations are optional and help cover the server and the domain.

Does this website track me?

No. It uses no cookies, no analytics and loads nothing from other websites.
